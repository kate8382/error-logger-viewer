# Настройка VS Code и решение проблем

Этот документ содержит подробные инструкции по настройке VS Code и решения распространенных проблем при работе с проектом Error Logger & Viewer.

## Первоначальная настройка

1. **Установите рекомендуемые расширения** (будет предложено автоматически при открытии проекта):
   - ESLint - для проверки кода
   - Prettier - для форматирования кода
   - Path Intellisense - для автодополнения путей к файлам
   - Auto Rename Tag - для переименования HTML/JSX тегов

2. **Конфигурация рабочего пространства VS Code** включена в папку `.vscode/` с:
   - Оптимизированными настройками для проекта
   - Конфигурациями отладки для frontend и backend
   - Полезными задачами для разработки

## Распространенные проблемы VS Code и их решения

### 1. Проблемы с ярлыком/запуском VS Code (Windows)

**Проблема**: "Объект code.exe, на который ссылается этот ярлык, изменен или перемещен, и ярлык больше не работает. Вы хотите удалить этот ярлык?"

**Решения**:

1. **Переустановите VS Code**:
   - Скачайте последнюю версию VS Code с [https://code.visualstudio.com/](https://code.visualstudio.com/)
   - Запустите установщик и выберите "Добавить в PATH"
   - Новая установка исправит сломанные ярлыки

2. **Исправьте существующий ярлык**:
   - Щелкните правой кнопкой мыши на сломанном ярлыке VS Code
   - Выберите "Свойства"
   - В поле "Объект" обновите путь на: `C:\Users\{ВашеИмяПользователя}\AppData\Local\Programs\Microsoft VS Code\Code.exe`
   - В поле "Рабочая папка" установите: `C:\Users\{ВашеИмяПользователя}\AppData\Local\Programs\Microsoft VS Code\`
   - Нажмите "ОК"

3. **Создайте новый ярлык**:
   - Перейдите в папку установки VS Code (обычно `C:\Users\{ВашеИмяПользователя}\AppData\Local\Programs\Microsoft VS Code\`)
   - Щелкните правой кнопкой на `Code.exe` → "Отправить" → "Рабочий стол (создать ярлык)"

4. **Альтернативные способы запуска**:
   - Нажмите `Win + R`, введите `code`, нажмите Enter
   - Откройте Командную строку/PowerShell, введите `code .` в папке проекта
   - Найдите "Visual Studio Code" в меню Пуск

### 2. Настройка для работы с проектом

**Правильное открытие проекта**:
```bash
# Способ 1: Командная строка (рекомендуется)
cd /путь/к/error-logger-viewer
code .

# Способ 2: Меню VS Code
# Файл → Открыть папку → Выберите папку error-logger-viewer
```

**Настройка среды разработки**:
1. Откройте VS Code в корневой папке проекта
2. Нажмите `Ctrl+Shift+P` (Cmd+Shift+P на Mac)
3. Введите "Tasks: Run Task" и выберите это
4. Выберите "Install Backend Dependencies" и дождитесь завершения
5. Запустите "Install Frontend Dependencies"
6. Запустите "Start Backend" и "Start Frontend" в отдельных терминалах

### 3. Проблемы с расширениями и конфигурацией

**ESLint не работает**:
```json
// Добавьте в settings.json VS Code при необходимости
{
  "eslint.workingDirectories": ["frontend", "backend"],
  "eslint.validate": ["javascript"]
}
```

**Проблемы с форматированием Prettier**:
- Установите расширение Prettier
- Установите как форматировщик по умолчанию: `Ctrl+Shift+P` → "Format Document With" → "Prettier"

**Автодополнение путей не работает**:
- Установите расширение "Path Intellisense"
- Перезапустите VS Code

### 4. Проблемы с терминалом и задачами

**Ошибка политики выполнения PowerShell (Windows)**:
```powershell
# Запустите в PowerShell от имени администратора
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**Node.js не найден**:
- Установите Node.js с [https://nodejs.org/](https://nodejs.org/)
- Перезапустите VS Code после установки
- Проверьте командой `node --version` в терминале VS Code

### 5. Настройка отладки

**Конфигурация отладки**:
- Нажмите `F5` или перейдите на панель "Запуск и отладка"
- Выберите "Launch Full Application" для запуска и backend, и frontend
- Устанавливайте точки останова, щелкая по левому полю
- Используйте "Debug Backend" для отладки серверной части

## Рабочий процесс разработки

**Рекомендуемый рабочий процесс**:
1. Откройте проект: `code .` в терминале или Файл → Открыть папку
2. Запустите серверы разработки:
   - Нажмите `Ctrl+Shift+P` → "Tasks: Run Task" → "Start Backend"
   - Нажмите `Ctrl+Shift+P` → "Tasks: Run Task" → "Start Frontend"
3. Код с включенным автоформатированием и проверкой
4. Используйте конфигурации отладки для устранения неполадок

**Полезные горячие клавиши**:
- `Ctrl+`` ` - Переключить терминал
- `Ctrl+Shift+`` ` - Новый терминал
- `Ctrl+P` - Быстрый поиск файлов
- `Ctrl+Shift+P` - Палитра команд
- `F5` - Начать отладку
- `Ctrl+F5` - Запуск без отладки

## Чек-лист для устранения неполадок

Если VS Code работает неправильно:

- [ ] VS Code установлен и обновлен до последней версии
- [ ] Проект открыт как папка (не отдельные файлы)
- [ ] Node.js установлен и доступен в терминале
- [ ] Установлены необходимые расширения
- [ ] npm зависимости установлены в frontend и backend
- [ ] Нет конфликтующих расширений или настроек
- [ ] VS Code перезапущен после изменения конфигурации

При постоянных проблемах попробуйте:
1. Перезагрузить окно: `Ctrl+Shift+P` → "Developer: Reload Window"
2. Сбросить настройки VS Code: Временно удалите `.vscode/settings.json`
3. Чистая переустановка: Полностью удалите VS Code, удалите папку настроек, переустановите
